COMPARISON SUMMARY
==================

1. PREPROCESSING
   - Both datasets clipped to Bologna municipal boundary, filtered to buildings > 5 m²
   - Buildings ≤ 5 m² excluded (removes shelters, garages, etc.)
   - Cadastral height: altezza_gr, fallback to quota_gron − quota_pied where altezza_gr is missing

2. GEOMETRY MATCHING

   Method: sjoin (intersects) + largest overlap area as best-match criterion.

   Strategies evaluated:
   ┌─────────────────────────────────────────┬───────────────┐
   │ Method                                  │ Matched (GBA) │
   ├─────────────────────────────────────────┼───────────────┤
   │ sjoin intersects + largest overlap      │ 50,974  ✓     │
   │ sjoin_nearest, max_distance = 5m        │ 51,956        │
   │ sjoin_nearest, max_distance = 10m       │ 52,329        │
   │ Intersection over Union > 0.3           │ 43,586        │
   │ Intersection over Union > 0.5           │ 34,545        │
   └─────────────────────────────────────────┴───────────────┘

   Selected: sjoin intersects + largest overlap
   Rationale: requires physical overlap between polygons, is parameter-free,
   and the marginal gain from distance-based matching (~2.6%) does not justify
   the risk of false matches between adjacent buildings.

   Low IoU values reflect genuine polygon fragmentation — GBA and cadastral
   frequently represent the same physical structure with different polygon
   boundaries. Documented as a limitation of the height comparison statistics.

   Implementation note: matching is asymmetric — one GBA polygon can overlap
   multiple cadastral polygons and vice versa. Two separate deduplications
   computed from the same raw join:

     best_per_gba  — one row per GBA building (largest cadastral overlap)
                     used for height comparison and gap-filling (= joined_all)
     best_per_cad  — one row per cadastral building (largest GBA overlap)
                     used only for cadastral-side coverage counts

4. HEIGHT COMPARISON
   Note: counts use best_per_gba (one row per GBA building).
         best_per_cad gives 57,817 matched cadastral buildings, 52,671 with height.

   Matched buildings (GBA perspective):
   - Geometrically matched              : 50,974
   - Matched + height in GBA            : 50,974  (GBA always has height)
   - Matched + height in cadastral      : 48,832  (from best_per_gba pairs)
   - Matched + height in BOTH           : 48,832  ← used for all stats below
   - Matched but cadastral missing ht   :  2,142  (candidates for gap-fill)

   Threshold sensitivity (n = 48,832 pairs):
   - ± 1 m  →   8,197  (16.8%)
   - ± 3 m  →  22,809  (46.7%)
   - ± 5 m  →  33,057  (67.7%)

   Mean signed bias (GBA − cadastral) = −2.51 m
   GBA systematically underestimates relative to cadastral.
   Supports using cadastral as primary source.
